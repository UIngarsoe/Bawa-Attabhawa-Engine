## ၁။ ယုတ္တိဗေဒရဲ့ ကောင်းကျိုး

Logic မကောင်းဘူးလို့ ပြောတာ မဟုတ်ပါ။

တကယ်တော့ Logic ဟာ လူသားအသိဉာဏ်ရဲ့ အလွန်တန်ဖိုးရှိတဲ့ ကိရိယာတစ်ခု ဖြစ်တယ်။

Logic က

မဆီလျော်တဲ့ အကြောင်းပြချက်တွေ ဖမ်းပေးတယ်။

Contradiction တွေ ရှာပေးတယ်။

အကြောင်းနဲ့ အကျိုးကို ခွဲစဉ်းစားစေတယ်။

Assumption တွေကို ထုတ်ဖော်စေတယ်။

Argument တစ်ခု ဘယ်လိုတည်ဆောက်ထားသလဲ ပြပေးတယ်။

ကိုယ့်အမြင်ကို ကိုယ်ပြန်စစ်နိုင်စေတယ်။


ဒါကြောင့်

 Logic မရှိရင် အမှန်တရားရှာဖွေရာမှာ လမ်းပျောက်နိုင်တယ်။

Logic က သူ့ထံပေးထားတဲ့ အချက်အလက်တွေကို အမြဲတမ်း အမှန်လို့ မစစ်ပေးနိုင်ဘူး။

ဒါကြောင့်

## ၃။ Logic က ဘာကို မမြင်နိုင်လဲ?

Logic ဟာ လက်တွေ့ကမ္ဘာထဲက မရောက်နိုင်တဲ့အရာတွေကို ကိုယ်တိုင်သွားမတွေ့နိုင်ဘူး။

စာရွက်ပေါ်မှာ

 A → B → C

C က အခြားအကြောင်းကြောင့် ဖြစ်နိုင်သလား?

ဆိုတာတွေက logic တစ်ခုတည်းနဲ့ မဖြေရှင်းနိုင်ဘူး။

## ၄။ “Simulation” ရဲ့ Blind Spot

ဒီနေ့ ကျွန်တော်တို့ ဖန်တီးခဲ့တဲ့ radio broadcast ကို စဉ်းစားကြည့်။

Radio host ရှိတယ်။

Caller တွေ ရှိတယ်။

မြို့သူမြို့သားတွေ မေးခွန်းမေးတယ်။

Host က ပြန်ဖြေတယ်။

အားလုံးက အလွန်ယုံကြည်စရာကောင်းတဲ့ simulation ဖြစ်နိုင်တယ်။

ဒါပေမယ့်

 Simulation ≠ Field Reality



AI က လူတစ်ယောက်ရဲ့ စကားပြောပုံကို အလွန်ကောင်းကောင်း simulate လုပ်နိုင်တယ်။

ဒါပေမယ့်

အဲဒီလူ တကယ်ရှိခဲ့ကြောင်း မသက်သေပြဘူး။

AI က ဝမ်းနည်းနေတဲ့ လူတစ်ယောက်ရဲ့အသံကို ရေးပေးနိုင်တယ်။

ဒါပေမယ့်

တကယ်ဝမ်းနည်းနေတဲ့လူရဲ့ ဘဝအတွေ့အကြုံကို မဖန်တီးပေးနိုင်ဘူး။

ဒါကြောင့်

Simulation is a laboratory.
Reality is the final test.

## ၆။ “အသံ” က Intelligence ဖြစ်နိုင်သလား?

ဖြစ်နိုင်တယ်။

ဒါပေမယ့် အသံတစ်ခုကြားရုံနဲ့ အရာအားလုံးကို အမှန်လို့ မသတ်မှတ်ရဘူး။

ဥပမာ

“ကျွန်မတို့ ဒီနေ့ စားစရာမရှိဘူး။”



ဒါဟာ လူတစ်ဦးရဲ့ တကယ့်အတွေ့အကြုံကို ဖော်ပြတဲ့ testimony ဖြစ်နိုင်တယ်။

အဲဒီအသံကို

 “ဒါက subjective ဖြစ်လို့ intelligence မဟုတ်ဘူး”

လို့ ပယ်ချလိုက်ရင်လည်း မှားနိုင်တယ်။

တစ်ဖက်မှာ

“လူတစ်ယောက်ပြောတာဆိုတော့ တစ်နိုင်ငံလုံး ဒီလိုဖြစ်နေတယ်”

လို့ ချဲ့လိုက်ရင်လည်း မှားနိုင်တယ်။

ဒါကြောင့် ပညာရှိက

အသံကို နားထောင်တယ်။
အသံကို အလေးထားတယ်။
အသံကို အခြားသက်သေတွေနဲ့ ဆက်စပ်တယ်။
ဒါပေမယ့် အသံတစ်သံတည်းကို တစ်နိုင်ငံလုံးအတွက် သက်သေအဖြစ် မချဲ့ဘူး။
